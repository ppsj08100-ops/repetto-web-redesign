# REPETTO

Figma 디자인의 헤더부터 Brand News와 푸터까지 구현한 정적 웹사이트입니다.

## 실행

Node.js 20 이상에서 처음 내려받은 뒤 의존성을 설치합니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다. 다른 포트는 `npm run dev -- --port 3000`으로 지정합니다.

```sh
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. `scripts/build.mjs`가 `index.html`, 실행 소스와 이미지·폰트 자산을 같은 폴더 구조로 복사해 동적으로 사용하는 이미지도 포함합니다. 개발 서버와 미리보기 서버는 하나씩 실행합니다.

GitHub에는 소스와 `package-lock.json`을 올리고, `node_modules/`, `dist/`, 임시 파일은 `.gitignore`로 제외합니다. GitHub Pages에 배포할 때는 `npm run build`로 만든 `dist/` 내용을 Pages 아티팩트로 사용합니다. 문서·자산 경로는 상대 경로를 사용하므로 `/저장소이름/` 같은 하위 경로에서도 같은 구조로 배포할 수 있습니다.

## 구성

```text
Repetto_web/
├── index.html
├── package.json
├── package-lock.json
├── README.md
├── src/
│   ├── js/          # 실행 모듈과 인터랙션
│   └── styles/      # 공통·섹션 스타일과 폰트 선언
├── assets/          # 이미지·폰트·외부 라이브러리
├── scripts/         # 빌드·로컬 서버 도구
├── docs/            # 스타일 가이드와 작업 기록
└── archive/
    └── about-3d/    # 사용하지 않는 3D 시안, 빌드에서 제외
```

- `src/js/app.js`, `src/styles/styles.css`: 헤더, 히어로, 슈즈 슬라이더, 메뉴와 컬렉션 확대 화면
- `src/js/site-intro.js`, `src/styles/intro.css`: 첫 방문 오르골 인트로, 건너뛰기와 히어로 연결
- `src/js/music-box-model.js`: 크림색 상자·핑크 튤 발레리나의 오르골 모델
- `src/js/hero-motion.js`: 히어로 사진의 곡선 마스크 펼침과 Prev·Next 전환
- `src/js/shop.js`: 슈즈 연속 드래그·루프·자동 재생과 호버 DRAG 커서
- `src/js/shoe-images.js`: 공식 고해상도 사진을 기존 투명 실루엣에 맞춰 표시
- `src/js/sections.js`, `src/styles/sections.css`: About, Try On, Essential, Balletwear
- `src/js/about-type-motion.js`: 원본 드레스 사진 위 두 문구의 단어 마스크·스크롤 교체·역방향 복원
- `src/js/try-on-motion.js`: Try On 사진 커튼·제목 진입과 스크롤 움직임
- `src/js/ballet-motion.js`: Balletwear 사진 확대 진입·서로 다른 사진 스크롤 속도·문구 등장
- `src/js/essential.js`: Essential 사진 6장의 펼침·역스크롤 재쌓기와 열별 스크롤 이동
- `src/js/circle-hover.js`: 큰 VIEW MORE의 원·글자 포인터 추적과 부드러운 복귀
- `src/js/savoir.js`, `src/styles/savoir.css`: Savoir Faire의 고정 화면·스크롤에 따른 사진 카드와 이야기 전환
- `src/js/news.js`, `src/styles/news.css`: 실제 레페토 소식과 공식 원문 링크
- `src/js/footer.js`, `src/styles/footer.css`: 사이트 카테고리, 공식 소셜 링크, TOP 버튼
- `src/styles/fonts.css`, `assets/fonts/`: 로컬 폰트와 배포 라이선스
- `assets/images/`: Figma 원본 이미지 및 노드 매핑 `asset-manifest.json`
- [docs/styleguide.md](docs/styleguide.md): 원본 디자인 실측 및 스타일 가이드
- [docs/WORK_STATUS.md](docs/WORK_STATUS.md): 작업 이력과 유지 조건

메뉴 열기·닫기, 섹션 이동, 이미지 슬라이더의 버튼·드래그·방향키 탐색, 컬렉션과 슈즈 이미지 확대를 지원합니다. 작은 화면에서는 별도의 세로 레이아웃을 적용합니다.

첫 방문에는 아이보리 화면 중앙에서 작은 크림색 오르골이 열리고 핑크 튤 발레리나가 회전합니다. 오브제는 PC 약200px·모바일 약150px로 여백을 넉넉하게 두며, 약2.3초 동작과0.55초 페이드 뒤 기존 히어로 사진으로 이어집니다. 무음이며 `SKIP INTRO`와 Escape로 바로 건너뛸 수 있습니다. 같은 탭의 재방문, 모션 감소 설정, `#about` 같은 직접 링크에서는 인트로를 생략합니다. Three.js는 인트로가 필요한 경우에만 로컬 파일을 읽고, 종료 시 렌더러를 정리합니다. WebGL을 사용할 수 없으면 본 화면으로 진행합니다.

왼쪽 스크롤 진행선은 MARNON 레퍼런스와 동일하게 화면 왼쪽 50px, 세로 중앙에 고정합니다. 폭 2px·높이 140px의 반투명 회색 트랙 안에서 차콜 선이 페이지 스크롤 비율만큼 아래로 채워지며, 768px 이하에서는 숨깁니다.

슈즈 영역의 DRAG 링은 정적 버튼이 아닌 포인터 추적 표시입니다. 정밀 마우스를 사용하는 769px 이상 화면에서 슬라이더를 가리킬 때만 나타나며, 터치 화면에서는 실제 스와이프로 탐색합니다. 모션 감소 설정에서는 자동 재생과 이동 애니메이션을 생략합니다.

Essential은 Figma `639:397`을 바탕으로 같은 크기의 사진 6장을 단정한 부채꼴로 겹칩니다. 앞의 핑크 사진은 거의 반듯하게 두고, 뒤 사진들은 최대8도의 작은 각도 차이로 배치했습니다. 아래로 들어오면 펼쳐지고, 위로 스크롤해 영역 시작으로 돌아오면 같은 더미 모양으로 다시 모입니다. 움직이는 도중 방향을 바꿔도 현재 위치에서 이어집니다.

실제 사진 6개를 공통 레이어에서 이동하며 복사본은 만들지 않습니다. 펼침 완료 시 사진을 각자의 기존 위치로 돌려놓고 임시 레이어와 빈 슬롯을 제거합니다. PC는3열,768px 이하는2열이며 최종 배열·간격은 유지합니다. 모바일 설명은 사진이 펼쳐진 후 나타납니다. 모션 감소 설정에서는 움직임 없이 완성된 배열을 표시합니다.

큰 VIEW MORE 두 개는 원본처럼 원과 글자가 포인터에 부드럽게 반응하며, 글자는 원 이동량의 30%만 따라갑니다. 호버하면 8개 글자가 20ms 간격으로 위로 롤오버하고, 두 번째 SVG 선이 1초 동안 그려집니다. 이탈하면 중앙으로 복귀하며, 모바일·터치와 모션 감소 설정에서는 이동을 생략합니다. 링크·버튼의 위치와 클릭 동작은 유지합니다.

작은 링 버튼7개와 큰 원 버튼2개의 글자는 `#5269AD`로 통일했습니다. 기본 링/테두리는 `#7086CB`, 호버 선은 `#5269AD`입니다. 글자는 기본·호버·키보드 포커스 모두 같은 블루를 유지합니다.

Hero·슈즈·Savoir Faire 카운터는 Manrope Medium500·고정 폭 숫자로 통일했습니다. PC/태블릿14px·간격14px, 768px 이하12px·간격12px이며, 모두 실제 `/` 문자와35% 차콜을 사용합니다. 앞자리0 없이 `3 / 4`, `5 / 10`, `2 / 3` 형태로 표시하며, Hero의 세로 배치와 슈즈 카운터 클릭 기능은 유지합니다.

About은 원래 고화질 사진을 유지하며 두 영문 문구를 표시합니다. 첫 문구 `YOUR MOST / beautiful MOVES`는 원본과 같은9/15자, 두 번째 `START WITH / TRUE freedom.`은 원본11/13자에 가까운10/13자입니다(공백·마침표 포함). 이어 읽으면 “Your most beautiful moves start with true freedom.”이 됩니다. `beautiful`·`freedom.`은 사이트의 Cormorant Garamond 이탤릭입니다. 이전 `Beyond / The Stage` 문구는 이 최신 요청으로 대체했습니다.

[Vero Studio](https://www.verostudio.com/)의 공식 코드·CSS를 확인해 단어별1.4초/80ms간격 진입과300ms퇴장, 두 문구의 교체·두 번째 문구의 상승/페이드, 아래 소개문 진입을 연결했습니다. `100svh + 1800px`의 sticky 구간과351단계 스크롤 시계를 사용하며, 역스크롤도 같은 시점을 따릅니다. 사진은 원본 비율을 그대로 유지한 채 세로로 이동합니다. PC96px·모바일38px와768~1280px의 유동 크기를 사용하고 좁은 화면은 두 줄이 맞도록 줄입니다. 모션 감소 또는 높이539px 이하에서는 사진·두 문구·소개문을 자연스러운 정적 흐름으로 표시합니다.

거부된 입체 모델은 다시 사용하지 않습니다. `archive/about-3d/about-motion.js`, `archive/about-3d/about-3d.js`, `archive/about-3d/about-mannequin.js`는 비활성 시안으로만 소스에 남겨 두고 배포 모듈 목록에서 제외했습니다. 실제 3D 회전을 적용하려면 원본 드레스의 형태·질감에 맞는 정교한 모델을 먼저 확보해야 합니다.

두 줄 영문 도입문은 DM Mono Regular·PC16~24px(1440px 화면18px)·태블릿16px·모바일14~16px입니다. 영문 행간135%, 세 줄 한국어 Pretendard Regular·행간175%·PC/태블릿16px·768px 이하14px를 유지합니다. 영문→본문24px·본문→버튼32px(태블릿 이하28px), VIEW ALL의 공통15px/모바일12px와 블루도 유지합니다.

About은 Figma에서 다시 추출한 `about-dress-hq.png`(2542×2772px,2배 출력)를 표시합니다. 원본 실제 해상도1201×1310px의 `about-dress-original.png`와 이전939×1024px 파일도 보존했습니다. 이 사진 자체의 형태·크롭·색·투명도는 변경하지 않았습니다.

POP UP SHOP은 내장 `image_gen`으로 새로 만든 매장 전체 콘셉트 `popup-store-pop-up-v4.png`를 사용합니다. 레페토 공간의 발레 바·곡선 슈즈 진열을 참고한 제안 이미지이며, 실제 특정 매장을 촬영한 사진은 아닙니다. 원본과 이전 버전은 보존했고, 생성 프롬프트는 `popup-store-pop-up-v4.prompt.txt`, 출처는 manifest의 `derivedAssets`에 기록했습니다.

Try On의 두 카드는 MARNON 실측과 같은 64% 컨테이너 안에45.2%/31.3% 폭,320px 높이 차이로 배치합니다. 사진은 원본의908:1381/628:902 비율로 채우며, 사진과 제목의 왼쪽 끝선을 일치시켰습니다. 사진→제목14px, 설명→버튼42px입니다. 768px 이하에서는 두 사진 모두 안쪽 너비의68.57%로 가운데 정렬하고 카드 간격80px, 사진→제목24px/제목→설명8px/설명→버튼25px를 사용합니다. 현재 사진·문구·순서·버튼 색상은 유지합니다.

매장·팝업 소개와 Balletwear의 한글 설명은 최신 요청에 따라 PC·모바일 모두 Pretendard16px로 통일했습니다. 매장 설명의 기존200% 행간과 Balletwear의150% 행간을 유지하며, 좁은 화면에서는 단어 단위로 자연스럽게 줄바꿈합니다.

Try On 움직임은 [MARNON 공식 CSS](https://marnon.jp/assets/css/app.css)·[JS](https://marnon.jp/assets/js/bundle.js)를 확인해 적용했습니다. 각 사진이 진입하면 회색 커튼이 아래에서 차오르고 위로 걷히며, 사진은1.05배에서1배로 돌아옵니다. 커튼/사진 클립은1초·지연450ms, 사진 확대 복귀는1초·지연500ms입니다. 제목5글자는80ms 간격으로100px 아래에서 올라오고 클립이 풀립니다. 제목에만1.1배 속도의 패럴랙스를 적용하며, 긴 매장명과 겹치지 않도록 좁은 화면의 이동 범위를 제한합니다. 한 번 드러난 사진은 역스크롤해도 유지합니다. VIEW MORE는 기존 블루 링 축소와 함께8글자가20ms 간격으로 롤오버하며, 모바일과 모션 감소 설정에서는 글자 롤오버를 생략합니다.

슈즈 8개는 레페토 공식 원본 JPEG(894~2500px)로 교체했고, 제품 사진의 픽셀을 재생성하거나 확대 가공하지 않았습니다. 크림 CENDRILLON은 동일 사진의 큰 원본을 찾지 못했고, ZIZI GOMME의 큰 공식 사진은 촬영 각도가 달라 기존 사진을 유지합니다. 출처·원본 치수·배치 좌표는 `assets/images/shoe-image-sources.json`에 기록했습니다. 히어로 역시 동일한 고해상도 원본을 확보하기 전까지 기존 Figma 사진을 유지합니다.

## Balletwear 영상

`Custom Ballet Looks`는 [MARNON 원본](https://marnon.jp/)의 제목·설명·원형 버튼 정렬을 반영했습니다. PC는 오른쪽 정렬 제목과 들여쓴 설명을 하나로 묶어 264px 원과 세로 중앙을 맞춥니다. 모바일은 제목/설명을 왼쪽으로, 원을 오른쪽으로 배치합니다. 원본의 Adobe Garamond Pro와 현재 Cormorant Garamond의 차이를 고려해, 최신 요청에 따라 제목 두 줄 행간은110%에서100%로 줄였습니다. 한글 설명의150% 행간은 유지합니다.

Balletwear의 움직임도 [MARNON 공식 CSS](https://marnon.jp/assets/css/app.css)·[JS](https://marnon.jp/assets/js/bundle.js)를 참고했습니다. 대제목10글자는80ms 간격으로 아래100px에서 올라오며, 큰 사진은60% 크기·아래200px에서1.5초 동안 펼쳐집니다. 큰 사진과 타원은 각각1.04/1.08 속도로 독립적으로 움직입니다. 본문 영역에 진입하면 Custom이 먼저, Ballet·Looks가150ms 뒤에 아래50px에서 나타나고, 한글 두 줄은40px 아래에서 서서히 올라옵니다. 모바일에도 같은 흐름을 적용하며, 모션 감소 설정에서는 즉시 표시하고 사진 이동을 생략합니다. 원형 버튼은 기존 호버·확대창 동작을 사용합니다.

타원형 슈즈 사진은 원본의 `22.694vw`·최대420px 크기로 줄이고 PC에서 왼쪽13.3%에 배치했습니다. 큰 사진 아래 글/원 버튼까지는 PC20px, 모바일25px로 좁혔습니다. 휴대폰에서는 기존 타원 사진 크기를 유지하며, 원본의 166px 상단 위치를 사용해 제목과 겹침을 방지합니다. 큰 사진과 Balletwear 대제목의 크기·위치는 유지합니다.

Figma가 재생 가능한 영상 URL을 제공하지 않아 해당 VIDEO fill의 원본 포스터를 사용합니다. 원본 영상 파일을 확보한 뒤 `src/js/sections.js`의 `.ballet-film`에 있는 `data-video-src`를 로컬 영상 경로로 지정하면 `initSections()`가 영상 요소로 전환합니다.

Savoir Faire는 이야기 영역에 진입하면 한 화면으로 고정되고, 세로 스크롤에 따라 사진이 앞·중간·뒷장 순으로 왼쪽 위로 날아갑니다. `Athlier` → `Making` → `Materials`로 이어질 때 다음 사진 묶음이 살짝 올라오며, 이전 제목이 사라진 뒤 새 제목과 설명이 차례로 나타납니다. 각 새 이야기에는 잠깐 머무는 스크롤 구간을 두고, 마지막 사진을 남긴 뒤 고정을 해제합니다. 역스크롤은 같은 경로로 복원되며, Prev·Next와 좌우 방향키·Home·End도 해당 이야기의 세로 위치로 이동합니다. 원본 사진9장과 문구는 유지합니다.

모바일도 사진·제목·설명이 한 화면 안에 들어오며, 터치는 기본 세로 스크롤을 사용합니다. 고정 중 화면 크기가 바뀌어도 현재 사진 진행도를 유지합니다. 모션 감소 설정과 높이540px 미만의 가로 화면에서는 세 이야기를 일반 문서 흐름으로 표시합니다. 카운터의 접근성 안내는 이야기 번호가 바뀔 때만 갱신합니다.

## Brand News · Footer

NEWS는 [레페토 코리아 공식 뉴스](https://www.repetto.kr/news/main.asp)에서 2026-11-09 확인한 실제 게시일과 원문 링크를 사용합니다. 한글 제목은 시안의 행 너비에 맞게 줄인 표현이며, 항목을 선택하면 공식 원문이 새 탭에서 열립니다. 뉴스 데이터는 `src/js/news.js`의 `brandNews`에서 관리합니다.

뉴스 행은 MARNON 원본처럼 날짜·분류·제목이 함께 오른쪽 15px로 1초 동안 이동하고 오른쪽 화살표가 그려집니다. 구분선은 호버와 키보드 포커스에도 같은 색을 유지합니다. 768px 이하에서는 움직임과 화살표를 생략하며, 모션 감소 설정에서는 위치를 유지하고 화살표를 즉시 표시합니다.

푸터는 회원 혜택 안내, 컬렉션·브랜드 메뉴, 고객지원·약관, 팔로우 안내로 구성했습니다. 회원가입·매장찾기·배송/환불·FAQ·고객 서비스·멤버십·약관 링크는 레페토 코리아 공식 목적지를 사용합니다. 하단에는 사용자가 제공한 회사·사업자·통신판매·개인정보 책임자 정보와 2026년 저작권 문구를 모두 표시합니다. 전화번호와 이메일은 직접 연결할 수 있습니다. 소셜 아이콘은 Figma 원본 SVG와 공식 SNS 주소를 사용합니다.

푸터는 은은한 블러시 배경에 작은 일반 세리프 문구(PC30px/모바일26px)와 SNS를 가운데로 정렬했습니다. 그 아래 회원가입 안내와 네 카테고리는 추가 구분선 없이 여백으로 구분하며, 모바일 메뉴는 두 열입니다. 전체는 최대1600px 중앙 정렬이고 회사 정보는 종이색 하단 영역에 표시합니다. 카테고리4개·메뉴12개와 전체 문구·19개 링크·회사 정보는 유지했습니다. 1920~320px의 12개 화면 폭에서 내용 보존·실제 글자 잘림 없음·TOP 동작을 확인했습니다.

상단 이동 버튼은 글자 없이 가는 화살표만 표시합니다. PC48px/모바일44px의 작은 원형 버튼을 화면 오른쪽 아래에 고정하고, 화면 높이의75% 이상 스크롤하면 나타납니다. 숨겨졌을 때는 키보드 초점에서도 제외됩니다. 클릭하면 상단으로 부드럽게 이동하고 모션 감소 설정에서는 즉시 이동합니다. 푸터 하단 여백을 확보해 회사 정보와 겹치지 않으며, 1440/1024/768/375/320px에서 고정 위치·실제 클릭·키보드 초점·모션 감소·정보 겹침 없음을 확인했습니다.
