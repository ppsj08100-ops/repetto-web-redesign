## 1. 문서를 읽는 기준

**실측값**은 Figma 노드의 속성에서 확인한 값입니다. 단위는 별도 표시가 없으면 `px`이며, 부동소수점 오차는 읽기 쉽게 반올림했습니다. 색상은 RGB를 8비트 HEX로 변환했습니다. 노드 크기는 글자의 실제 외곽이나 이미지 원본 해상도와 다를 수 있습니다.

**시각적 해석**은 화면에서 관찰한 조형 원칙입니다. **구현 제안**은 원본에 없는 웹 구현 기준입니다. 이 문서의 CSS 변수명과 역할명은 문서화를 위해 제안한 이름이며, Figma에 등록된 토큰명이 아닙니다.

실제 확인 결과, 로컬 변수 컬렉션·텍스트 스타일·페인트 스타일은 각각 0개이며 대상 하위 노드의 변수 바인딩도 없습니다. 따라서 반복되는 값을 역할별로 정리하되, 원본의 서로 다른 값을 임의로 하나로 합치지 않습니다.

## 2. 시각적 방향

다음은 원본 화면에 대한 **시각적 해석**입니다.

- 크림색 바탕과 연한 핑크색 면을 넓게 사용하고, 짙은 웜 그레이 텍스트로 대비를 만듭니다.
- 300~340px 크기의 Cormorant Garamond 제목이 섹션의 중심을 잡습니다. 제목과 사진이 겹치는 구성이 반복됩니다.
- 영문 내비게이션·버튼에는 Manrope, 설명·날짜·카운터에는 DM Mono, 한글에는 Pretendard를 사용합니다.
- 인물·의상·슈즈 사진을 크게 배치합니다. 사진은 주로 직사각형이며, Balletwear에는 세로 타원 사진을 사용합니다.
- 비대칭 열, 서로 다른 이미지 크기, 사진 카드의 회전과 중첩, 긴 세로 여백으로 편집물 같은 리듬을 만듭니다.
- 작은 두꺼운 링과 텍스트를 조합한 CTA, 큰 가는 원형 CTA가 반복됩니다.
- 선택 프레임 하위에서 활성화된 그림자·블러 등 효과는 확인되지 않았습니다. 깊이감은 이미지 중첩과 배치로 표현합니다.

## 7. 이미지·영상·섹션 구성

### 7.1 이미지 사용 원칙

다음은 원본 관찰에 근거한 **구현 제안**입니다.

- 사진의 주 피사체, 원본 비율, 크롭 방향을 함께 보존합니다. 모든 사진을 동일한 `aspect-ratio`로 통일하지 않습니다.
- Figma의 이미지 fill은 주로 `FILL`입니다. 웹의 `object-fit: cover`를 출발점으로 삼되 각 슬롯의 크롭과 위치를 별도로 맞춥니다.

- Balletwear의 큰 미디어 `639:440`는 정지 사진이 아니라 `VIDEO` fill입니다. 스크린샷에 보이는 한 프레임을 정지 사진 에셋으로 오인하지 않습니다.
- 원본 레이어 이름이 `Bride in a veil`, `Model wearing denim and handmade shoes`여도 실제 화면의 피사체와 다를 수 있습니다. 이미지 렌더링과 노드 ID를 함께 확인합니다.
- 에셋 파일은 아직 이 프로젝트에 내려받지 않았습니다. 추후 구현 시 Figma 원본 이미지·SVG·영상을 확보해 로컬 경로로 관리합니다. 만료되는 MCP 에셋 URL을 영구 경로로 사용하지 않습니다.

## 9. 반응형 구현 제안

선택 프레임은 1920px 데스크톱 시안입니다. 이 문서에서는 대응하는 모바일·태블릿 시안이나 breakpoint를 확인하지 않았습니다. 다음 값은 **Figma 실측값이 아닌 초기 구현 제안**입니다.

| 화면 폭 | 제안 방향 |
| --- | --- |
| 1440px 이상 | 중앙 콘텐츠 최대 폭 약 1410px, 여백을 유동적으로 조절하고 대형 구도 유지 |
| 1024~1439px | 좌우 여백 40~64px를 시작점으로 조정, 제목·이미지를 함께 축소 |
| 768~1023px | 좌우 여백 24~40px, 매장·사진 배열의 열 수와 중첩을 재조정 |
| 767px 이하 | 좌우 여백 20~24px, 매장 카드를 세로로 쌓고 뉴스 행을 재배치 |

- 300~340px 제목을 좁은 화면에 그대로 적용하지 않습니다. `clamp()` 등을 사용하되 사진과의 관계 및 의도된 줄바꿈을 검토합니다.
- 본문 폰트 크기는 데스크톱 화면 전체를 비례 축소하는 방식으로 줄이지 않습니다.
- 370px 원형 CTA는 작은 화면에서 별도 크기가 필요합니다. 정확한 모바일 크기는 미확정입니다.
- 회전된 메뉴·뉴스 라벨은 작은 화면에서 수평 배치를 검토합니다.
- 모바일 메뉴의 모양과 동작은 원본에 없으므로 별도 설계가 필요합니다.
- 고정된 19391px 문서 높이 대신 콘텐츠에 따라 높이가 결정되도록 구성하는 것을 제안합니다.

## 10. CSS 토큰 초안

아래는 **실측값을 웹 변수로 옮긴 구현 제안**입니다. 기존 코드나 Figma 변수의 추출물이 아닙니다. 역할별 제목·본문 값은 위 표를 기준으로 추가합니다.

```css
:root {
  --font-ui: "Manrope", "Pretendard", sans-serif;
```

## 12. 구현 결과 검수 기준

다음은 이 시안을 구현할 때 사용할 **제안 체크리스트**입니다.

- [ ] 1920px 기준에서 섹션 순서, 사진 비율, 대제목 위치, 주요 중첩이 원본과 맞는다.
- [ ] 크림 배경과 두 핑크 배경, 코럴·레드·주황 CTA가 구분된다.
- [ ] 4개 폰트 패밀리와 실제 굵기가 로드되고 한글이 의도한 폰트로 표시된다.
- [ ] `AUTO` 행간, 특이한 고정 행간, 자간, 대소문자 변환을 역할별로 확인했다.
- [ ] 사진마다 원본 에셋과 크롭이 맞고 임시 Figma URL이 남아 있지 않다.
- [ ] Balletwear의 VIDEO fill을 영상으로 구현하고 재생 방식과 대체 이미지를 확인했다.
- [ ] 작은 링은 45px·10px 테두리, 큰 원은 370px·1px 테두리의 데스크톱 기준을 따른다.
- [ ] Essential의 카드 회전·사진 열·CTA 겹침과 Balletwear의 타원 크롭을 보존했다.
- [ ] 페이지에 불필요한 가로 스크롤이나 텍스트 잘림이 없다.
- [ ] 링크·메뉴·슬라이더를 키보드로 사용할 수 있고 포커스가 보인다.
- [ ] 실제 메뉴 목적지, 임시 카피, 미완성 구간, 작은 화면 구성을 최종 확인했다.
